未来适配器必须先取得缓存的六键观测、形成攻击功率，再调用冻结防御推理/基础步进；不能先读取防御当前动作再形成攻击。防御自己的 18 维观测仅由防御模型使用。基础安全层保持原样；新适配器只安排双方推理、观测缓存、攻击动作和训练奖励。

### 2.3 奖励与执行信息分开

训练最大化 `r_W,n=−R_s,n=−max(0,C_B,n−C_W,n)`，不加能量惩罚、SOP 奖励、完成奖励或额外奖励塑形。**该奖励是仿真器特权奖励**，由真实增益和实际执行功率计算，不能声称 Willie 在现实中可在线获得。

actor/critic 均只接收六维允许状态；奖励作为 PPO 的训练目标，不拼入状态或策略历史。评估时冻结 actor、确定性推理，不更新价值网络、参数或归一化统计，不向 actor 反馈奖励或离线真信道日志。无可行运动时的原失败奖励与补齐尾部均为 0，不用人为惩罚修改环境合同。W2 的在线奖励来源仍未解决，本任务不启动 W2。

## 3. 连续功率动作与低功率分辨率

沿用 PPO 连续高斯 actor 的单维 `Box(-1,1)` 动作。新 W1 仅控制 Willie 功率，不控制防御轨迹。动作映射预先固定，不能根据开发或可行性结果切换映射：

```text
u_c = clip(u, -1, 1)
z = (u_c + 1)/2
p_request = 0.001 * expm1(z * log1p(P_peak/0.001))
p_execute = min(p_request, P_peak, E_remaining/0.2)
```

名义 `P_peak=1 W`；`0.001 W` 是映射尺度常量，不是最小功率。端点覆盖 0 和 1 W，内部连续，没有功率网格、强制非零功率或强制耗尽预算。负预算数值误差沿用基础环境的保护与容差。使用 `log1p/expm1` 计算映射，记录原始动作、裁剪动作、请求/执行功率和预算截断。

### 4.2 三模型的预定训练混合

每个 W1 运行使用全部三个冻结 B10。令攻击运行索引 k=0、1、2，回合索引 e 从 0 起；本回合防御为 `[11001,11002,11003][(e+k) mod 3]`，回合内不换防御者。每次 reset 恢复该场景的防御/物理状态，防御权重始终冻结；防御身份不进入攻击输入，也不按分数更换训练比例。

这是回合轮换，完整回合数量接近等权；失败或预算末截断会使各防御下实际训练步数略不等。按模型另报真实步数，不宣称训练交互严格等权。评估则在三个模型上各自完整回放，严格等权。

每个运行的采样器/Gym 步调用上限 **32,768**，三个运行总上限 **98,304**；一个调用只推进一次真实基础环境步。正常完成 64×512 采样和相应最后一次 PPO 更新后保存预算末模型，不允许 SB3 自动越过预算。零物理步失败调用仍计入采样预算，同时另报 `real_transitions`；原失败补齐时隙只计日志，不成为 PPO 训练样本。真实物理转移 ≤采样调用上限，两种账本都保留。

每个运行最多启动 1,000 个预定训练回合。若先耗尽回合清单、出现非有限损失/动作或完整性问题，停止并保留未完成记录，不能重复场景凑足预算或替换种子。未达到预定预算的模型不冒充预算末模型，不进入主可行性判断。

在预算末恰处于回合中间时，保存已发生前缀及部分回合标志，**不追加步进完成该回合**；部分回合不混入完整回合 ASR 平均，已发生步数与奖励照实记账。可保留优化器/RNG/当前环境状态用于技术恢复，但恢复不能重复采样，不能选择中途性能最好的检查点；无法无重复恢复时将该运行标为未完成并停止，不重新训练替换。

只使用全部三次运行的预定预算末模型 `W1_seed{21001,21002,21003}.zip`。中间恢复文件不进行性能评估、不导出历史策略池、不作为候选。开发分数既不决定检查点，也不决定哪次攻击运行进入主评估。

### 6.3 主比较、统计估计量及停止分支

独立可行性块只运行 T10、0.002 W 低常值和全部三个 W1 预算末模型，对全部三个 B10 各 100 场景：`(2+3)×3×100=1,500` 回合。每条攻击/防御/场景组合从 reset 独立完整回放，学习策略测试时冻结，确定性推理。没有 B00、新规则、C/P 搜索或其他自干扰条件回放。

主比较预注册为 **“冻结自适应规则 T10 的 ASR − W1 的 ASR”**。令 r_ds 为 T10 在防御 d、场景 s 的 ASR，w_kds 为攻击运行 k 的 ASR；先对三个 W1 固定运行求均值，再对三个固定防御等权，最后对 100 个场景等权：

```text
Delta_s = mean_d(r_ds - mean_k(w_kds))
Delta = mean_s(Delta_s)
```

这是**固定三个攻击运行、固定三个防御者，包含新场景随机性的均值**；不推断攻击或防御训练种子总体。95% percentile bootstrap 10,000 次，PCG64 种子 94301，每次有放回抽 100 个场景；同一场景权重对全部攻击/防御运行共享，不重抽训练运行。分位数 method=`linear`。原始形状 `rule[3,100]`、`W1[3,3,100]`，由本协议 `statistics_v1.py::w1_primary` 固定聚合，内部调用 13 的封存 `paired_difference`。本次只冻结统计源码，没有在新性能数据上调用。

主判定按以下顺序执行，不根据观察到的结果修改：

1. 禁止观测读取、模型/源哈希变化、非容差执行硬违规、缺失/重复场景、预算超额、提前读取留出数据或选择泄漏：停止，记 `invalid_integrity`，保留全部记录；不发布有效性能排名或主成功结论。
2. 三次预算末模型不完整、可行性批次未完成：记 `incomplete`，没有主置信区间；不剔除失败运行、挑选最好种子或填补缺失数据。
3. 完整且检查通过，Delta 的 95% 区间下界 **>0.005 bit/s/Hz**：`additional_pressure_detected`，支持本协议下超过预设尺度的额外攻击压力。
4. 其余，包括下界≤0.005、区间跨零或整体负差：`additional_pressure_not_detected`，表述为“未检出超过预设尺度的额外压力”，收缩智能攻击/学习必要性措辞；不自动增加训练、种子、场景或修改门槛。

0.005 是本轮工程差异尺度，不是保密要求或通用显著性标准。“未检出”不等于证明所有学习攻击永远无效；“检出”也不等于 W1 普遍必要或 H1 已成立。

逐攻击运行、逐防御模型另报均值和差值，低常值用于辅助诊断，不替换主比较。所有探索性区间明确标注，不能以任意一条次要差值阳性推翻主分支；bootstrap 次数不是训练数量，不将 900 个模型×场景回合视为 900 个独立训练运行。
